YouTube Summary Tool

プライバシーポリシー

更新日：2026年10月3日

このポリシーは、個人用のYouTube Summary Toolによるデータの取り扱いを説明します。本アプリはYouTube API Servicesを利用します。データは、本人が同意した情報収集・要約・動画登録の機能に使用します。

1. アクセスするデータと用途

  • 登録チャンネルの情報：本人の登録チャンネルのID・名称を取得し、新着動画を選ぶために使用します。
  • 動画の情報：動画ID・タイトル・説明文・チャンネル名・公開日時・動画URLなどを取得し、調査・要約・出典の表示に使用します。利用できる場合は対象動画の字幕も要約に使用します。
  • 所有者のチャンネル・動画の情報：投稿先チャンネルの確認、重複投稿の確認、処理状況や字幕の確認に使用します。
  • 投稿用ファイル：本人が指定した動画・タイトル・説明文・サムネイル・字幕を、動画登録のためにYouTubeへ送信します。
  • 認証情報：Googleが発行するOAuthアクセストークン・更新用トークンを、同意した権限でAPIへ接続するために使用します。Googleアカウントのパスワードは取得しません。

2. 保存と管理

認証情報、取得した動画情報、要約、投稿用ファイル、投稿の再開に必要な処理状態は、所有者が管理する端末のローカルファイルとして保存します。認証情報は公開サイトや公開リポジトリへ掲載しません。投稿専用の認証情報はアクセス権を制限したファイルに保存します。

現在のアプリでは、保存したAPI取得データの更新・削除は所有者が管理します。全保存データを一定期間で自動削除する機能はありません。取得時点の情報と最新の情報を区別して扱います。

3. 外部サービスへの送信

認証・チャンネル情報の取得・動画登録にはGoogle / YouTubeのAPIを使用します。要約機能では、対象動画の字幕・タイトル・チャンネル名・説明文・動画URLや生成済みの要約をGoogleのGemini APIへ送信します。Gemini APIを利用する際の入力・出力の取り扱いは、同サービスの利用条件にも従います。要約入力へOAuthトークンやアカウントのパスワードを含めません。

所有者が別途指示した場合、要約や自作の動画・記事を他のサービスへ移したり公開したりすることがあります。その操作は、そのサービスと公開対象についての個別の指示に基づき行います。

本アプリ側でGoogleユーザーデータを販売したり、広告のターゲティングや汎用AIモデルの学習に使用したりすることはありません。外部サービス側のデータの取り扱いは各サービスの条件をご確認ください。

4. 同意の撤回とデータ削除

Googleアカウントの接続済みアプリ管理画面から、本アプリへのアクセス許可を取り消せます。許可の撤回だけでは、既に保存されたローカルファイルが自動で削除されるわけではありません。

保存済みデータの削除については、Google OAuth同意画面に表示するサポートメールへ依頼するか、個人利用の所有者が認証ファイルと対応する取得データ・処理記録を削除します。削除は所有者が確認して実行します。ローカルファイルの削除によって、YouTube上の動画やチャンネルが削除されることはありません。YouTube上の動画はYouTube Studioなどで別途管理します。

5. この紹介サイトの情報

紹介サイトにはログインフォーム、広告、独自のアクセス解析、追跡用スクリプトを設けていません。サイトを提供するGitHub Pagesはセキュリティのため閲覧者のIPアドレスを記録します。詳しくはGitHubのプライバシーステートメントをご確認ください。

6. 問い合わせ・関連ポリシー

問い合わせはGoogle OAuth同意画面のサポートメール、または公開問い合わせ窓口で受け付けます。公開窓口へ認証情報・非公開動画の情報・個人情報を投稿しないでください。

GoogleプライバシーポリシーとYouTube利用規約もご確認ください。利用目的が変わる場合はこのページを更新し、必要な同意を得てから利用します。
